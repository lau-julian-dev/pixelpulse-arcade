04 Arranque

Tres pasos y a jugar.

Sin npm install, sin bundler. Solo Node para el servidor local, y ni eso si prefieres abrir el archivo directo.

01
Clona

Descarga el repositorio desde GitHub.

git clone https://github.com/lau-julian-dev/pixelpulse-arcade.git
02
Levanta

Arranca el servidor estático sin dependencias.

cd pixelpulse-arcade && node server.js
03
Juega

Abre el arcade en tu navegador. También funciona con doble clic en play.html.

open http://localhost:3000/play.html
Game over? Nunca
